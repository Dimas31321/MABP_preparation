# Практикум по МАБП

Статический сайт для подготовки к контрольной по моделированию и анализу бизнес-процессов. HTML, CSS и обычный JavaScript; без сборки, npm и серверной части.

## Возможности

- Три пробника, по 15 заданий: 12 тестов и 3 открытых кейса.
- Тренировка: ответы и объяснения раскрываются под каждым заданием.
- Экзамен: 45 минут, разбор открывается после завершения.
- Автоматическая проверка тестов, включая множественный выбор.
- Самооценка кейсов по эталону.
- Повторение ошибок и продолжение незавершённой попытки.
- Сохранение в localStorage текущего браузера.

## Структура

```text
index.html    — разметка и подключение ресурсов
style.css     — оформление и адаптивность
questions.js  — банк вопросов и эталоны
app.js        — навигация, таймер, проверка и сохранение
.nojekyll     — отключение Jekyll для GitHub Pages
```

## Запуск

Открой папку в VS Code и запусти `index.html` через расширение Live Server. Альтернатива, если установлен Python:

```bash
python3 -m http.server 8000
```

Открой http://localhost:8000. Для стабильного сохранения прогресса используй HTTP-сервер, а не открытие файла через `file://`.

## Добавление в GitHub

Распакуй архив. Скопируй содержимое папки `mabp-practice` в свой репозиторий. Если в нём уже есть сайт, можно поместить файлы в отдельную папку, например `mabp/`: относительные ссылки ресурсов сохранят работоспособность. Не перезаписывай существующий `index.html` без проверки.

Закоммить и отправь изменения привычным способом — через VS Code, GitHub Desktop или Git.

## GitHub Pages

Для отдельного репозитория с этими файлами в корне:

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку с кодом (например, `main`) и папку **/(root)**.
4. Сохрани настройки и дождись публикации. Адрес появится в разделе Pages.

Если проект находится в папке `mabp/` уже опубликованного сайта, открой `/mabp/` по адресу этого сайта. Для существующего проекта с React, Vite или другой сборкой эти файлы нужно интегрировать в его структуру отдельно.

## Как менять задания

Редактируй `questions.js`. Формат теста:

```js
q(
  1, // номер пробника: 1, 2 или 3
  'SIPOC',
  'Что является выходом процесса ремонта?',
  ['Мастер', 'Проверить устройство', 'Исправное устройство', 'Сервисный центр'],
  [2], // индексы правильных ответов с нуля; [0, 2] для множественного выбора
  'Выход — результат процесса, передаваемый потребителю.'
);
```

Открытый кейс:

```js
open(1, 'SIPOC', 'Составь SIPOC процесса ремонта.', 'Эталон ответа...');
```

Идентификаторы назначаются по порядку добавления. После изменения порядка вопросов старый сохранённый прогресс может относиться к другим вопросам: поменяй ключ `mabp-v1` в `app.js`, например на `mabp-v2`. При изменении числа заданий обнови описания и фиксированное число тестов на главной странице.

Таймер задаётся в `app.js` выражением `45 * 60000`; при изменении длительности обнови также подписи в интерфейсе.

## Ограничения

Это учебный тренажёр, а не защищённая экзаменационная система: правильные ответы доступны в исходном коде. Открытые кейсы автоматически не оцениваются. Прогресс хранится в браузере, не синхронизируется между устройствами и может удалиться при очистке данных сайта. Шрифт Manrope загружается из Google Fonts; без сети используется системный шрифт.

Вопросы составлены по темам предоставленных экзаменов 2022–2024 годов; это авторские тренировочные задания, не официальные билеты.
